# Model credits

By [Kenney](https://kenney.nl), licensed CC0 1.0 Universal (public domain —
no attribution required, listed here for reference only).

| Folder | Pack | Models | Source |
|---|---|---|---|
| `nature-kit/` | Nature Kit | 330 (full pack) | https://kenney.nl/assets/nature-kit |
| `fantasy-town-kit/` | Fantasy Town Kit | 167 (full pack) | https://kenney.nl/assets/fantasy-town-kit |

`nature-kit/` models are flat-shaded (no texture, just per-part solid
color). `fantasy-town-kit/` shares a `Textures/colormap.png` — each
`.glb`'s material references it via a relative path, so keep the `.glb`
files and the `Textures/` subfolder together.

Everything else previously here (Castle Kit, Graveyard Kit, Survival Kit,
KayKit Dungeon Remastered, KayKit Resource Bits) was removed along with
the castle system — see git history if any of it's wanted back.
