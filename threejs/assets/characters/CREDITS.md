Both packs by [Kay Lousberg](https://kaylousberg.itch.io/) (same artist behind
Kenney's official character kit), licensed CC0 1.0 Universal — free for any
use, no attribution required. Pulled from the official GitHub mirrors:
- https://github.com/KayKit-Game-Assets/KayKit-Character-Pack-Adventures-1.0
- https://github.com/KayKit-Game-Assets/KayKit-Character-Pack-Skeletons-1.0

| Folder | Characters | Role |
|---|---|---|
| `adventurers/` | Barbarian, Knight, **Mage**, Rogue, Rogue (Hooded) | Mage = player character. The rest are NPCs. |
| `skeletons/` | Skeleton Mage, Skeleton Minion, Skeleton Rogue, Skeleton Warrior | Graveyard enemies. |

Each `Characters/` folder has the rigged/animated `.glb` files plus the
character's `_texture.png` (single gradient atlas, same approach as the
Kenney world kits). `Accessories/` in each pack holds separate weapon/prop
models (swords, staves, shields, bows, etc.) as `.gltf` + `.bin` pairs, for
if/when characters need visible equipped gear.
