| Folder | Characters | Role |
|---|---|---|
| `adventurers/` | Barbarian, Knight, **Mage**, Rogue, Rogue (Hooded) | Mage = player character. The rest are unused for now. |

Each `Characters/` folder has the rigged/animated `.glb` files plus the
character's `_texture.png` (single gradient atlas). `Accessories/` holds
separate weapon/prop models (swords, staves, shields, bows, etc.) as
`.gltf` + `.bin` pairs, for if/when characters need visible equipped gear.

The Skeletons pack (graveyard enemies) was removed along with the castle
system — see git history if it's wanted back.
